# 1.4.3 光生波段默认值

新建性能页面、没有显式保存波段的设置以及新导入能带层使用 300–1100 nm。新增独立宽波段文献条目，使默认的光谱 TMM 配置可以直接运行；未向旧表拼接或外推数据。默认边界材料仍为 ITO、ITO/200 nm、Ag/100 nm，来源改为明确标注作者的宽波段表。

旧项目显式保存的 300–800 nm 和旧内置键名保持原值，避免历史结果因升级而被悄悄更改。打开旧文件后若希望改到1100nm，需要同时更换覆盖不足的旧光学数据。研究文件中已经保存的1100nm及自定义n,k继续使用原值。缺数据仍报错；完整 AM1.5G 的入射功率归一化不变。

数据依据及重建：见 [PROVENANCE](../assets/optics/PROVENANCE.md)、固定原始 YAML 与哈希清单。新增 MAPI 和 ITO 均为文献样品代理，不代表用户样品，也不能代替1.25eV锡铅钙钛矿的专用数据。

验证范围：默认全部材料和光学边界覆盖1100nm；旧ITO仍保持800nm并在越界时明确拒绝；显式800nm设置保留。真实SimSS运行检查光生、J–V、EQE、入射功率及电流守恒；Tk检查新页面默认值、光谱模拟与参数保存/打开。
