# 1.5.2 按钮悬停底色修复

用户反馈：圆角按钮悬停时四周出现灰色矩形，影响外观。

## 原因与修改

圆角图片使用透明边角；按钮仍继承Clam主题的底层背景状态映射。普通按钮在悬停时背景变为`#eeebe7`，按下时变为`#bab5ab`，禁用时为`#dcdad5`，矩形底色通过透明区露出。

`TButton`固定各状态的底层背景为白色内容面，普通按钮、蓝色/紫色强调按钮、图表按钮继承该设置。菜单按钮同步固定底色。圆角图片自身的悬停、按下、焦点、禁用颜色以及选中提示继续生效，尺寸和命令不变。

## 验证

- 在真实1.5.1窗口复现“设为对照”按钮悬停灰色外框；在1.5.2核对普通按钮、J–V/EQE运行按钮、叠层页及图表工具栏。
- 检查6种样式在普通、悬停、按下、禁用、焦点+悬停、选中+悬停共36种组合下的底色，均保持`#ffffff`。
- 3项既有Tk集成测试通过：按钮/页签尺寸、图表平移缩放/历史/选中状态、三个页面的独立输入复制。
- 更新单文件及文件夹版到`dist/1.5.2/`。模拟模型、引擎及器件参数不变。
- GitHub单文件上传完成并核验SHA256；文件夹版两种上传方式分别连接中断/超时，保留本地ZIP，发布页不提供失效下载链接。
