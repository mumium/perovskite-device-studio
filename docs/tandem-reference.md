# 两子电池串联参考（1.4.1）

此模式建立正确的同电流串联基准，不是已经实现真实20n/20p连接区的自洽隧穿仿真。普通J–V仍是原来的整体异质结计算，两者独立显示和保存。

## 使用

在性能页点击「两子电池串联参考…」，确认分界位于n层和p层之间，填写连接面电阻后运行。0表示假设零额外连接压降，正数表示假设的欧姆连接损失。窗口同时显示两个子电池和串联参考的Jsc、Voc、FF、效率及曲线。完整JSON可导出；再次通过「打开参数」打开参考JSON时，进入独立参考窗口，不覆盖常规页输入和结果。

参考窗口使用打开时的参数快照；修改主页面的材料后，请重新打开参考窗口。窗口内修改分界或连接电阻后，已有结果保留至重新运行成功，导出文件始终对应最后一次成功计算。

也可直接打开参数库中的「串联参考输入」文件：原始能级版本，或上一轮能级及减反设计版本。它们使用新的独立项目类型，需要1.4.1；旧版会拒绝该类型。

## 计算方式

1. 只对完整光学堆栈进行一次光生计算。保持入射AM1.5G功率100mW/cm²，按照中间n/p位置拆分同一G(x)，没有给两个子电池各自再照一次完整太阳光。
2. 分界两侧使用虚拟选择性内接触。内接触功函数按端点净掺杂的非简并近似推算：n侧为χ+kT ln(Nc/Nd,net)，p侧为χ+Eg−kT ln(Nv/Na,net)。这是一项明确的边界假设，不是新增物理材料，也不预测真实接触压降或真实载流子跨界面隧穿。
3. 使用SimSS分别计算两个子电池J–V。子电池内Rs置0，Rsh置1E12 Ω·cm²；全器件原Rs、Rsh仅在合成时施加一次。
4. 在共同内部电流Js下：Vi=Vtop(Js)+Vbottom(Js)−Js·Rc/1000；Jext=Js−1000Vi/Rsh；Vext=Vi−Jext·Rs/1000。电流单位mA/cm²、电阻Ω·cm²。这里全局Rsh并联在理想子电池串联支路两端，全局Rs在其外侧。
5. 合成后重新从曲线计算四项指标。不会把两条曲线按相同电压相加，也不会把原Voc乘倍数；分母仍是一次完整入射功率。

光生拆分积分须守恒，子电池重映射的总光生误差须小于1%，否则不采用。电流反演仅容许小于max(1E-4 mA/cm², 1E-4 Jsc)的反偏饱和数值起伏，修正幅度写入JSON；明显非单调或未覆盖串联工作范围的子电池曲线直接拒绝，不外推补齐Jsc。

## 当前适用范围

- 面向此次1.78/1.25eV、左光入射、左空穴/右电子接触的结构。分界左端净n掺杂、右端净p掺杂均须为正且低于相应态密度；不允许把简并重掺杂直接带入Boltzmann内接触估算。
- 当前子电池内部扫描分别为−1.6至1.65V和−1.6至1.25V，未覆盖有效开路点或共同电流区间会报错。
- 采用固定G(x)、理想选择性虚拟边界，未包括实际连接区非局域隧穿、简并统计、自洽准费米能级转换及连接非线性I–V。输入Rc只是敏感性假设，不是由掺杂和材料自动计算的连接电阻。
- 光学源数据沿用前研究的代理组成、NiOx/PTAA映射及SiO2透明近似，未新增实验标定。所有参考结果均不能直接证明实际材料连接有效或器件达到相应效率。
- 目前未提供两个子电池的偏置EQE求解；常规页EQE不会自动变成叠层子电池EQE。

1000/2000网格的实际案例见[串联参考重建报告](../research/2026-11-15/01_series_reference/README.md)。参考模型得到约2.07–2.09V，只说明同电流串联基准已建立；真实n/p连接模型仍待建立和验证。
