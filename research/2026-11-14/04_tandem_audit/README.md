# 钙钙叠层电学拓扑核查及此前结果适用范围更正

后续进展：1.4.1已新增[独立串联参考](../../2026-11-15/01_series_reference/README.md)，以同一光生源、虚拟选择性内接触验证同电流电压相加。它没有实现真实20n/20p连接的自洽隧穿；本页关于旧结果适用范围的更正继续有效。

2026-11-14。结论：此前双吸收层及其n/p过渡结构未建立并验证有效的两子电池串联连接；约0.92V、28%–29%的结果属于现有双吸收层模型，不可作为成熟两结全钙叠层的性能预测或结构优越性证据。原始结果保留以供追溯，不再以它们确认叠层优化成功。

## 找到的问题

1. **中间连接没有实现预期功能。** 两层20nm渐变区域只是普通半导体层；中央n/p界面Nt=0，因此适配器写出的界面SRH复合通道为零。`transfer_n/p`只是同载流子的层间传输速度，不是将前子电池电子与后子电池空穴连接起来的隧穿/复合连接模型。体内双分子和SRH复合依然存在，不能把“界面Nt=0”误读为整个器件没有复合。
2. **内置源码没有接入并验证带间隧穿连接。** 本项目使用的SimSS 5.36-pds1中，`DDRoutines.pas`的直接复合为同位置B(np−ni²)，另有体/界面SRH；没有发现实现该n/p接触带间隧穿的方程或适配参数。不能把普通B称为隧穿系数。此结论限定本项目所带版本及封装，不等于断言任何漂移扩散程序都不能模拟叠层。
3. **峰值1E16 cm⁻³不是已验证的隧穿结。** 当前Nc=Nv=3E18 cm⁻³，在300K的准中性非简并估算下，带边与费米能级相距约0.147eV。它不能凭名称就被当作n+/p+低阻连接；是否可用界面辅助复合或其他机制实现串联，必须建立对应模型并验证，不能简单把掺杂调高。
4. **此前优化目标偏向载流子共用端口收集。** 追求全部光生电流被同一端口输出、降低所有复合，适合双吸收层单结思路，却没有区分中央期望复合与吸收层损失复合。中央功能复合结与吸收层陷阱损失是不同的物理角色。一个真正的2T叠层也只有两个外部电极，问题不是外部电极数目，而是内部连接、选择性及两个子电池的准费米能级分裂没有获得验证。
5. **扫描范围也不适于检验2V以上Voc。** 旧参数Vmax=1.5V应在叠层核查时拓宽，但仅改扫描范围不能恢复缺失的连接物理。

## 新做的数值核对

将原n/p结构和最新减反n/p结构的扫描控制Vmax拓宽到2.6V，用1000点/16分段/0.02V检查。原结构Voc约1.333V，最新结构约0.9224V；两条完整曲线都只有一次由正光伏电流到负电流的跨零。没有漏掉一个位于2V以上的正常开路点。该核查不是正式2000点精度下的新性能优化。

注意SimSS扫描控制与外部电压不能混为一谈：源码使用`Vext=Vint+Jext*Rs`，大正向注入电流会令输出外电压远大于2.6V。文件中的外电压最大值不代表光伏电压增益；Voc以零电流点为准。

最新结构在短路时，宽侧原生光生电流参考约17.60mA/cm²、窄侧约18.17mA/cm²，外端Jsc约35.73mA/cm²，接近两者相加。在同一光学分配的理想两子电池串联基准里，电流应受较小子电池光生电流约17.60mA/cm²限制，电压才相加。这是当前结果缺乏正确串联行为的直接证据，不能以较大的Jsc和较低Voc冒充正常串联叠层。

额外试探了中央界面Nt=1E12/1E14 cm⁻²和峰值掺杂1E16/1E18 cm⁻³，原/最新结构共8组均未完整收敛，未采用任何部分曲线，也不能据此声称该物理结构必然失败。普通界面缺陷开关尚不是已经验证的复合连接修复。

## 正确的修正顺序

先建立光学一致的两子电池基准，在相同电流下相加电压：`Vtandem(J)=VWBG(J)+VNBG(J)−ΔVconnection(J)`；同一外部电流流过两子电池。开路时电压接近两个子电池Voc之和，但实际连接损失、漏电和非理想效应应独立检验。不能把28%的现有曲线直接乘以2V/0.92V。

用户要求不增加独立互联材料层仍然保留。中间已有的20n/20p区域可以作为拟研究的功能连接区，但需要物理适用、可收敛且经校核的连接模型。理想零损连接只能作为参考上界，不是实物预测；目前尚未完成真实n/p连接模型，也没有得到已验证的2V以上新结果。

修正后应重新检查：子电池Voc分裂和相加、层分辨Jn/Jp在连接处转换、电流匹配、相应偏置下的子电池EQE、数值收敛，之后才能比较厚度或能级方案。
