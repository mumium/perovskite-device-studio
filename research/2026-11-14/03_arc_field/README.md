# 电场、入光面减反与厚度优化（无互联层）

打开 [报告](进一步优化报告.html)。保留原电学结构，加85nm SiO2光学减反层后效率约28.11%；总1200nm下宽侧改50nm约28.44%；再沿用μ=20/τ=1ms并令Rs=0.1的额外假设约28.97%。各档分开比较，尚未达到30%。

参数分别为arc85、thin50和thin50_quality_rs01。SiO2为Malitson1965熔融石英n色散、k=0近似，实物膜及电极取电方式未校准。完整源数据见 [研究发布](https://github.com/mumium/perovskite-device-studio/releases/tag/research-2026-11-14-arc)。
