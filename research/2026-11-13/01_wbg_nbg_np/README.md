# 1.78 / 1.25 eV 双结构对比

打开 [双结构性能对比报告.html](双结构性能对比报告.html) 查看结果、J–V、结构/掺杂、光生分布及数值复核。

结构一：400 nm 宽带隙 + 800 nm 窄带隙。结构二：380 nm 宽带隙 + 20 nm n渐变 + 20 nm p渐变 + 780 nm 窄带隙。总钙钛矿厚度均1200 nm，NiOx20/C6040 nm另外计。

正式设置为2000点、32渐变分段、0.01 V。软件“器件性能模拟 → 打开参数”选择 parameters 中的 JSON，可复现正式结果。宽带隙χ=3.8 eV；窄带隙χ=3.9 eV。中间n/p接触端分别Nd/Na=1E16，向各自外侧降至1E14；原窄带隙吸收层仍为Nd=1E14、Na=0。p过渡层自身Nd=0。

光学仍为原Air入射、AM1.5G的300–800 nm、原MAPI表的吸收边近似，不是实测锡铅或宽带隙光学常数。没有新增隧穿复合连接层。这里只比较指定连续层栈，不把它直接视为校准的成熟叠层器件。

原计算设置及1000/1500/2000网格、48分段检查保留在完整数据包。完整数据包含 initial、grid1000、grid1500、refined、check48 中的原生结果JSON，参数和模拟器源码指纹见manifest.json，独立指标与UI重算见核对文件。报告结果保留网格敏感性，不声称已完全收敛。

仓库内为便于浏览的报告、参数、曲线/损失/光生数据及核对记录。完整原始快照和驱动脚本在研究发布包中。离线阅读无需安装软件；重算脚本需放在完整源码仓库的 results/本研究目录下，使用项目Python运行。
