# 双结构的文献光学与近红外扩展

打开 [文献光学与近红外对比报告.html](文献光学与近红外对比报告.html) 查看主结果、三种光学条件、J–V、n/k、光生与损失，以及EQE核对。

仅更新光学数据与300–1100 nm波段；电学层数、厚度、Eg、χ、掺杂、复合、寿命、电阻和其余电学设置不变，没有添加互联层。

主J–V为2000网格、32分段、0.01 V；独立EQE检查采用1000网格、16分段、20 nm步长，已有同分辨率J–V短路基线核对。EQE积分为微分响应参考，不等同于主表Jsc。

参数在parameters中，所有自定义n/k已内嵌。主参数用于J–V，复现报告EQE请使用单独的EQE_check参数，包含对应的1000网格、16分段、20 nm步长和1800秒超时。宽侧采用作者Br45%插值表（Tauc锚点1.78 eV），窄侧采用Sn50%重建表（锚点1.25 eV）；材料来自2026年公开预印本和数据仓库，因用户未给化学配方而按带隙选取，不是用户薄膜的实测校准。NiOx依旧保留PTAA示例光学映射，C60保留原表。Ag改为Johnson–Christy1972，Air沿用n=1,k=0定义。

数据仓库 https://github.com/akashdasgupta/Perovskite-Dielectric-Constants-Repository ，论文 https://arxiv.org/abs/2601.11793 。固定提交、文件SHA256与列选择见光学来源与核对.json。只读取n、k列，上游alpha数值单位已按公式复核，不依赖其表头单位。

仓库展示报告、参数、选定光学输入、紧凑曲线数据和核对记录；研究发布包保存完整原生输出与驱动脚本。解压可离线看报告；重算需在完整软件源码仓库的results/本研究目录中运行，现有manifest和内嵌参数足够复现计算，不需要再次联网下载整套源数据。
