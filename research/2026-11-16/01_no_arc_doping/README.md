# 无减反层叠层掺杂优化与数值复核

**结构适用范围更正：本研究改了两主吸收层的Nd/Na，并将中间n/p层的梯度方向反转，偏离“仅中央高掺杂、向两侧降低”的原设计。26.7191%只属于这套扩展结构及条件串联边界，不能作为原设计的优化成绩。原始数据保留供追溯，正确结构见[中央高掺杂纠正重算](../02_center_peak_np/README.md)。**

**最终推荐对照：21.0005% → 26.7191%，仅改变钙钛矿掺杂；未得到经过数值复核达到 30% 的方案。**

打开 [离线报告](报告.html)，其中含 J–V、Nd/Na 分布、性能参数、原始曲线、数值敏感性与未采用的高效率候选。GitHub 不直接执行 HTML，可下载本目录或发布页数据包后在浏览器中打开。

变化为 ΔJsc −0.229274 mA/cm²、ΔVoc +0.139539 V、ΔFF +13.861387 个百分点、ΔPCE +5.718632 个百分点。保持同一 Jsc、Voc 达到30%需要约89.34%的FF，当前仍不足。

结构仍为 NiOx 20 / 宽带隙380 / n层20 / p层20 / 窄带隙780 / C60 40 nm，Eg=1.78/1.25 eV；两主吸收层的 Nd 从0→1e17、Na从1e17→0，分别线性变化。n层 Nd从1e17→1e16，p层Na从1e16→1e17，另一掺杂种类为0。中间n/p端仍各为1e16。相对原输入，20nm层的浓度梯度方向也发生改变。其他物理参数、入射功率、光谱和n,k保持原值；Air/200nm光学占位不提供减反作用。

推荐输入：[线性掺杂优化](sensitivity/linear_fine_input.json)、[同网格基准](refined/baseline_fine_input.json)，也分别收录在仓库 `device_structures/2026-11-16_无减反叠层_线性掺杂优化.json` 和 `2026-11-16_无减反叠层_掺杂优化对照基准.json`。在叠层页打开后运行。推荐参数为2000空间点、28渐变分段、0.005V步长。

## 检查范围

- 纯掺杂：113个条件/子电池，共226个子电池条件；另以先前能级方案、移除减反膜作62个子电池条件对照。
- 两类共得到9824组可组合的共同电流粗筛曲线。粗筛使用缓存G(x)、500点/12分段/0.02V，允许有限重映射误差作排名，**不是最终效率**。原有软件的1%总光生重映射、电流守恒及单调性接受规则均未放宽。
- 完整重算与分辨率核查：推荐线性方案在26分段时26.7910%，0.01V步长时26.7354%；这组核对差异小于0.08个百分点，不是最终数学收敛证明。1000点/24分段/0.01V为27.0315%，主结论采用更细计算。
- 强对数渐变纯掺杂方案在1000点时曾为28.2134%，更细检查出现非单调曲线，未选作推荐。
- “既有能级设计＋对数渐变”粗筛最高30.2247%；完整计算、网格和步长变化后结果约27.89%–29.90%，未保持达标，未作为30%结论。此对照额外改了χ与外接触功函数，其收益不能算成纯掺杂收益。
- 原生溢出、不完整输出及非单调曲线均按原规则拒绝，未使用失败的部分结果。扫描失败及汇总保留可追溯记录。
