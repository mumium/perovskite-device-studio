在「器件性能模拟 → 打开参数」中选择 JSON。文件包括材料、电极、复合、光学、扫描及 EQE 设置，两层钙钛矿均开启光生载流子。保留提交时的原始参数，厚度优化结果不会反写进此文件。

当前结构的 NiOx 光学数据按原文件采用 PTAA 示例 n,k；渐变层吸收边参考带隙为 3.0 eV，均匀层为 1.53 eV。此处用于复现给定模型，不代表已校准的实验器件。

新增结构时请使用明确的文件名，在上表登记层顺序、入射方向和适用页面；自定义光谱与 n,k 应内嵌在参数文件中。

2026-11-13 两种新结构的参数文件对应加密计算结果，宽带隙χ=3.8 eV、窄带隙χ=3.9 eV。两侧吸收层仍保留原Nd=1E14、Na=0；新增p层自身Nd=0。沿用原MAPI光学近似及300–800 nm波段，未增加隧穿复合互联层，不能视为校准的成熟叠层模型。见 [双结构对比报告](../research/2026-11-13/01_wbg_nbg_np/README.md)。

文献光学版的n、k已内嵌，模式为固定n,k，避免再次进行MAPI吸收边映射。宽侧是作者Br45%插值、窄侧是Sn50%重建，按带隙选取代理组成，不是用户薄膜的实测校准；NiOx仍保留原PTAA示例映射。详见 [文献光学与近红外报告](../research/2026-11-13/02_extended_optics/README.md)。
